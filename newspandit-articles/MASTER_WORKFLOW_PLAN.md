## 5-STAGE PIPELINE FOR EACH STORY

### STAGE 1: INITIAL WRITE-UP (HINDI)
- Research provided links
- Write 300-700 word article in Hindi
- Create unique, fresh angle
- Document word count and reasoning
- Identify non-factual elements

### STAGE 2: RESEARCH & ENHANCEMENT  
- Search internet for missing points
- Find what other publications covered
- Identify SEO keywords
- List missing details/statistics
- Note expert opinions, latest developments

### STAGE 3: BACKLINKS & SOURCES
- Find internal links from newspandit.com sitemap
- Identify first-hand external sources (primary sources only)
- List relevant images with captions, alt text
- Prepare anchor text placement

### STAGE 4: FACT-CHECKING
- Verify each sentence for factuality
- Cross-check statistics, dates, quotes
- Identify inaccuracies
- Correct non-factual elements without changing other sentences
- Maintain language simplicity

### STAGE 5: SEO OPTIMIZATION
- Generate attention-grabbing titles (multiple options)
- Create meta descriptions (200 char)
- Select appropriate categories from sitemap
- Choose 2-5 relevant tags
- Create SEO-friendly slug
- Define 4-word focus phrase
- Add external/internal backlinks to anchor text
