### 1.2 Sitemap Configuration Best Practices
```xml
<!-- PROPER SITEMAP FORMAT -->
<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap>
    <loc>https://www.karmactive.com/post-sitemap.xml</loc>
    <lastmod>2026-04-29T05:46:47+00:00</lastmod>
  </sitemap>
  <!-- Each sitemap should have all required elements -->
</sitemapindex>
```

### 1.3 Add Missing Sitemap Attributes
- [ ] Add `<changefreq>` tags to each URL:
  ```xml
  <url>
    <loc>https://www.karmactive.com/article</loc>
    <lastmod>2026-04-29</lastmod>
    <changefreq>monthly</changefreq>  <!-- ADD THIS -->
    <priority>0.8</priority>           <!-- ADD THIS -->
  </url>
  ```

- [ ] Priority Guidelines:
  ```
  1.0 = Money pages (highest earning content)
  0.9 = Main category pages
  0.8 = Important articles
  0.5 = Secondary/older content
  0.3 = Tag pages, archives
  ```

## 4. ROBOTS.TXT & ADS.TXT OPTIMIZATION (1 DAY)

### 4.1 Create/Update robots.txt
```
User-agent: *
Allow: /
Disallow: /wp-admin/
Disallow: /wp-includes/
Disallow: /wp-content/plugins/
Disallow: /?s=
Disallow: /*/feed/
Disallow: /*?*trackback
Disallow: /trackback/

# Allow Google Bot to see CSS and JS
Allow: /wp-content/themes/
Allow: /wp-content/cache/

Sitemap: https://www.karmactive.com/sitemap.xml
```

**Location:** `/robots.txt` at domain root

### 4.2 Create/Update ads.txt
```
# Monetization Networks
google.com, pub-xxxxxxxxxxxxxxxx, DIRECT, f08c47fec0942fa0

# Secondary Networks (if using)

openx.com, xxxxxxx, RESELLER
```

**Location:** `/ads.txt` at domain root

**Note:** Get your publisher ID from each ad network and add to ads.txt

  - [ ] Use containers with fixed height
