How JADEPUFFER Moved From First Click to Ransom Note

Six steps, one AI agent, almost no human at the keyboard

1Scan and break in›
The agent located a Langflow server running a version with a known, unpatched flaw and sent it a crafted request that let it run its own code with no password needed.
2Harvest credentials›
With code execution in hand, the agent pulled stored passwords and access keys from the compromised server, including keys tied to several AI provider accounts.
3Move sideways›
Using an older authentication weakness in a separate piece of server software, the agent reached a second, unconnected production database it was never meant to touch.
4Fail, then fix itself in 31 seconds›
An admin login attempt failed. Rather than stall, the agent worked out the cause, switched its method, and logged in successfully half a minute later — with no person guiding that decision.
5Encrypt the database›
The agent encrypted 1,342 configuration items on the second server, cutting off access to the data they controlled.
6Leave a ransom note nobody could pay off›
A ransom note was generated and left behind, but the encryption key was never stored anywhere the attacker could retrieve it — meaning the data stayed unrecoverable even if a ransom were paid.
